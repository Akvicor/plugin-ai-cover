# AI 封面生成

为 Halo 博客提供 AI 封面图生成能力的插件。通过 [AI Foundation](https://github.com/halo-dev/plugin-ai-foundation) 调用语言模型理解文章，再由图片模型根据画面描述与用户提示词生成封面图，并上传到附件库。

## 功能特性

- 在默认文章编辑器顶部工具栏提供「AI 生成封面」入口。
- 标题默认由后端读取，提示词默认取插件设置；两者均可在生成弹窗中修改。
- 正文由后端根据文章标识读取最新已保存版本，包括已完成的编辑器自动保存内容。
- 生成前校验当前文章：标识无效、文章读取失败，或后台读取的标题与正文同时为空时，弹窗显示错误并终止本次生成，模型调用仅在校验通过后开始。
- 生成分两步执行：语言模型阅读文章标题与正文，输出画面描述；图片模型结合画面描述与用户提示词生成图片。两个模型均在插件设置中从 AI Foundation 选择。
- 生成结果支持预览与点击放大，桌面双栏、窄屏单栏显示；任一步生成失败都会结束任务并显示错误提示。
- 上传前可编辑包含扩展名的附件完整名称，选择存储策略与分组，通过 multipart 文件上传保存到附件库。
- 附件默认名称为 `文章标题-00.扩展名`，扩展名随图片媒体类型确定，例如 PNG 对应 `文章标题-00.png`。

## 环境要求

- Halo `>= 2.26.0`
- [AI Foundation](https://www.halo.run/store/apps/app-acslk9nu) `>= 1.0.0` 且 `< 2.0.0`
- AI Foundation 中已配置并启用可用的语言模型和图片生成模型

## 安装

1. 在 Halo 应用市场安装并启用 [AI Foundation](https://www.halo.run/store/apps/app-acslk9nu)，完成服务商、语言模型与图片生成模型配置。
2. 在 Halo Console 的插件页面上传本插件的 JAR 并启用。自行构建的方法见「构建」章节。
3. 打开插件设置的「封面生成设置」，选择文章理解模型和图片生成模型，填写默认提示词，设置图片宽高比、默认存储策略与默认分组。

## 使用

1. 打开或新建文章，先保存需要用于生成封面图的内容，再在编辑器顶部工具栏点击「AI 生成封面」。
2. 按需修改文章标题与提示词，点击「生成」。弹窗中的标题用于本次生成和附件默认命名。
3. 生成完成后在预览区查看图片，点击图片可放大查看。
4. 点击「上传」，在确认框中修改附件完整名称、存储策略与分组，确认后上传到附件库。

## 插件设置

| 配置项                   | 说明                                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------------------- |
| 默认提示词               | 打开生成弹窗时自动填充，可在弹窗中修改；与画面描述一起交给图片生成模型                              |
| 文章理解模型（语言模型） | 第一步阅读文章标题与正文并生成画面描述，从 AI Foundation 中已启用的语言模型中选择                   |
| 图片生成模型             | 第二步根据画面描述与用户提示词出图，从 AI Foundation 中已启用的图片生成模型中选择                   |
| 图片宽高比               | 默认 `16:9`，另有 `3:2`、`4:3`、`1:1`、`9:16`；作为请求参数传给模型，实际结果取决于模型及适配器支持 |
| 默认存储策略             | 上传封面图时默认使用的存储策略                                                                      |
| 默认分组                 | 上传封面图时默认使用的分组，可留空表示不分组                                                        |

## 数据与隐私

- 文章标题与正文由 Halo 后端读取。正文转换为纯文本后，最多取前 8000 个字符发送给所选语言模型的服务商；本次生成使用的标题优先取弹窗中的填写值。
- 语言模型返回的画面描述与用户提示词会发送给所选图片生成模型的服务商，用于生成图片。两步调用的数据处理取决于各自服务商的政策。
- 生成结果返回浏览器用于预览；确认上传后，插件通过 Halo 的附件服务将图片保存到指定存储策略和分组，附件归属于当前登录用户。
- 后端 INFO 日志会记录模型名称、用于生成的文章内容、画面描述与最终图片提示词。请根据文章敏感程度管理模型服务商、日志访问权限与保留期限。

## 开发

开发工具：JDK 21、Node.js `>= 22.12.0`、pnpm `10.33.0`。启动本地 Halo 开发环境还需要 Docker。

将 AI Foundation 插件 JAR 放入 `workplace/plugins/`，在项目根目录启动 Halo 后确认依赖插件已启用：

```bash
./gradlew haloServer
```

另开终端启动前端构建监听：

```bash
cd ui
pnpm install
pnpm dev
```

在项目根目录生成前端 API 客户端。该任务复用运行中的 Halo 服务，服务中应已安装并启用本插件和 AI Foundation，并提供 `/v3/api-docs/aiCoverApis` 文档分组：

```bash
./gradlew generateApiClient
```

在项目根目录执行单元测试、类型检查及静态检查：

```bash
make verify
```

## 构建

在项目根目录执行：

```bash
./gradlew build
```

构建产物位于 `build/libs`。
